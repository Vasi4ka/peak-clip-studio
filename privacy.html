Privacy Policy

This policy explains how Peak Clip Studio handles information when its owner connects and uses social-media accounts.

1. Information processed

The application may process the account identifier, display name, authorization scopes, access and refresh tokens returned by a platform, selected video files, captions, publishing settings, and the status or identifier of a requested upload.

2. Purpose

This information is used only to connect accounts requested by the user, display the correct destination account, upload content after explicit user action, and report the result of that upload.

3. Storage and security

Peak Clip Studio runs locally on the user's computer. OAuth secrets and tokens are stored in the operating system's secure credential store. The application does not sell personal information and does not use account data for advertising or profiling.

4. Platform services

When the user requests an upload, the necessary account data and media are transmitted to the selected platform, such as TikTok, Instagram, or YouTube, under that platform's own privacy policy and terms. Temporary transfer services may be used only when selected by the user and only for the time needed to transfer the chosen media.

5. Retention and deletion

Local connection data remains until the user removes the account from Peak Clip Studio or revokes access through the platform. Generated media remains on the user's computer until the user deletes it. To request help deleting locally stored application data, contact the address below.

6. User choices

The user chooses which accounts to connect, which scopes to approve, which content to upload, and the available privacy settings. Authorization may be revoked at any time from the connected platform's settings.

7. Contact

Privacy questions and deletion requests can be sent to peakgaming.media@gmail.com.
